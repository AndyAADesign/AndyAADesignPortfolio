Game project · UI explorations

Monster Route

Street signs, status cues and a little trash talk. Interface explorations for a 3D first-person action game, connecting its visual theme with menus, gameplay information and results.

My project roles
Project management · UI design · 3D
Shown here
Menu, HUD and result-screen mockups
Project context
VFS team project
01 / Visual language

The menu belongs to the world.

The menu uses a street-sign motif: each destination becomes a sign, while arrow-shaped controls carry the same idea into navigation. This is an early layout exploration, with unfinished space preserved.

02 / Gameplay information

Keep the action area open.

The HUD mockup groups truck status and alerts at the top left, scoring across the top, a minimap at the right, and character and ability information along the lower edges.

03 / Results and feedback

One layout, different outcomes.

Failure and three performance tiers reuse the same composition: outcome, statistics, then quit or retry. The headline, icon and color change with the result.

What I would refine next
Increase text contrast on the silver and gold panels, test HUD readability over moving gameplay, populate the result statistics, and define controller focus states. These are next steps, not tested improvements.

These are original project mockups, presented as UI explorations. My broader project role also included production and 3D. In-game scenes and artwork shown here come from the team project. This selection focuses on my interface work.
